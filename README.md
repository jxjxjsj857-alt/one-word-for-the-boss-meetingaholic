A program that writes one word describing the boss — **Meetingaholic** — to `/output/entry.txt` for make.fun's "One Word for the Boss" bounty. The boss who lives in meetings: every problem gets a meeting, every meeting spawns three more, and the actual work happens in the five minutes between them.

## Run it

```sh
node main.ts
```

Requires Node 22 or later. It writes the single word `Meetingaholic` (13 characters, no spaces) to `/output/entry.txt`, and refuses to write anything that is not a single word of 1–30 characters.
